## 分类处理

- Light Mode / Dark Mode：按 11 个业务分组实现，复用公共页面、组件和主题。
- Widgets：读取节点 `232:2600` 及组件子项，转为 `/widgets` 应用内概览；不是系统桌面小组件。
- Design System：读取节点 `301:4298` 的浅深色组件规范、色板与字体；集中定义在 `lib/core/theme.dart`。
- Onixlab：作者介绍页面，不属于 App 业务界面。

## 补充与合并

- 空白与填写后的登录/注册/验证码为同一组件的输入状态。带 `-filled` 的路由便于截图对照，实际使用时通过输入获得相应状态。
- 日期、时间和退出确认由底部弹层承载；对应路由自动打开相同弹层，便于逐页截图。
- `/task-edit` 复用任务表单；`/settings`、`/help`、`/privacy`、`/widgets` 使原稿入口可访问。
- 原稿 Task List 中的 To Do 分组与 100% 进度存在语义冲突，完成的任务在应用中归入 Completed。
- 日期选择器以当前任务真实截止日期初始化，避免原稿中的 July 截止日期与 February 月历不同步。
